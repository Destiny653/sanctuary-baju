1. Generate reference stills first (section 2). Pick the best image of each character and save it.

3. Paste the Locked Style Block and Character Blocks word for word at the start of every clip.

# PART 9: TROUBLESHOOTING

- Faces change between clips: re-attach the reference still as an Ingredient and shorten the prompt so the Character Block dominates.
- Skin lightens in bright scenes: add "deep brown skin clearly visible in the glowing light" to that clip only.
- Islamic-looking architecture appears: add "plain Roman-era Judean limestone, flat rooftops, no domes" and attach E1 or E2.
- Clip crowds too many actions: cut it to two beats.
- Portrait looks like a painting: add "documentary photography, natural skin pores, film grain".
- Portrait looks cartoonish: put "photorealistic, real person" at the very start.
- Crucifixion clip is filtered: keep the wording non-graphic as written, or generate only the wide Calvary shot.
- Flow limits prompt length: use the Character Blocks and one-sentence beats only.
