# Coachella (MadeType) — display headers

Drop licensed Coachella webfont files here, then prepend `url()` sources in `src/styles.css` `@font-face` rules for `"Coachella"`.

Expected filenames (any subset is fine):

- `Coachella-Regular.woff2` / `.woff`
- `Coachella-Medium.woff2` / `.woff`
- `Coachella-SemiBold.woff2` / `.woff`
- `Coachella-Bold.woff2` / `.woff`

Until files are present, headings fall back to Playfair Display (`--font-coachella-fallback`).
